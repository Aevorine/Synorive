# Synorive 电脑版操作指南

适用：Windows 10 / 11 x64。安装版和便携版操作完全一样，只有更新方式不同（见第 7 节）。

---

## 1. 装好之后第一件事

| 步骤 | 做什么 | 看到什么才算成了 |
| --- | --- | --- |
| 1 | 双击 `Synorive-Setup-<版本>.exe`，一路下一步 | 桌面出现 Synorive 图标 |
| 2 | 打开软件，等左下角状态栏的圆点变绿 | 圆点绿色 + 「引擎就绪」 |
| 3 | 按 `Ctrl+K`，输入一句话或几个词 | 主输入区展开占满中间 |
| 4 | 点「选一个文件夹开始索引」，选一个放资料的文件夹 | 状态栏出现「队列 N」并开始往下掉 |

圆点一直是红的 → 界面正中会摊开「缺什么、怎么补」，照着点「我自己装好了，重试」即可。
不用自己去装 Python，安装包里自带运行时。

## 2. 快捷键总表

### 2.1 全局（软件在后台也生效）

| 按键 | 作用 | 抢不到时会怎样 |
| --- | --- | --- |
| `Alt+空格` | 任何时候唤出搜索，不用先切窗口 | 自动退到 `Ctrl+Alt+空格`，设置页「全局快捷键」里会写明退到了哪个 |
| `Ctrl+Alt+S` | 截图直搜：框选屏幕任意区域，直接以图搜图 | 同上，退到备选键 |

`Alt+空格` 在 Windows 上本来是系统窗口菜单键，被别的软件占用是常见情况。
**设置 → 全局快捷键**页面会逐条列出「首选键 / 实际生效的键 / 一个都没抢到」，
不会出现"按了没反应也不知道为什么"。

### 2.2 窗口内

| 按键 | 作用 |
| --- | --- |
| `Ctrl+K` | 展开主输入区（最常用的一个） |
| `Ctrl+Shift+K` | 展开主输入区并切到「找东西」模式 |
| `/` | 展开主输入区（不在输入框里时） |
| `Ctrl+Shift+P` | 命令面板：所有功能按名字搜着用 |
| `Enter` | 在主输入区提交 |
| `Shift+Enter` | 在主输入区换行，不提交 |
| `Esc` | 收起主输入区 / 关掉当前抽屉 / 退出命令面板 |
| `Ctrl+Z` | 撤销上一步（删除、归档、清理这类） |
| `Ctrl+Shift+Z` | 重做 |

`Ctrl+Z` 在输入框里不生效——那时候它归输入框自己，抢过来会让人在打字时莫名恢复一条已删文件。

### 2.3 结果列表里（列表有焦点时）

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` | 上一条 / 下一条 |
| `PageUp` `PageDown` | 翻页 |
| `Home` `End` | 跳到第一条 / 最后一条 |
| `Enter` | 打开选中项 |
| `空格` | 勾选 / 取消勾选（用于批量操作和成稿） |
| `Esc` | 取消所有勾选 |

### 2.4 命令面板里

`↑` `↓` 选，`Enter` 执行，`Esc` 退出。直接打字就是模糊搜索命令名。

## 3. 鼠标指到哪里都有说明

导航栏的每个图标、界面里每个只有图标没有文字的按钮，**鼠标停住一秒就会浮出它的功能名**。
侧栏收起成一条图标栏之后也一样，不用为了看名字再展开。

---

## 4. 八个界面各管什么

| 界面 | 什么时候用 |
| --- | --- |
| 今日 | 打开就有东西看：新进库的、订阅到期的、没读完的研究 |
| 搜索 | 问一句话拿带出处的答案，或搜全部已索引内容 |
| 文件管理器 | 浏览、按类型/时间筛、清理重复图、回收站 |
| 分析中心 | 投喂新内容、看分析进度、整页存档、一张图四路并查 |
| 时间轴 | 按时间铺开全部内容 |
| 知识图谱 | 人物、地点、组织之间的共现关系 |
| 研究工作台 | 联网搜索、深挖简报、文献检索 |
| 设置 | 外观、性能、更新、同步、隐私、库管理 |

进入某个界面后左上角**不会**再重复一遍界面名——导航栏已经高亮着你在哪一页了。
顶部那一行小字只写"这一页现在是什么情况"（几条结果、几毫秒、正在忙什么），没有内容时整行不占地方。

## 5. 两种输入模式

主输入区右上角可以随时切，切换时已经打的字不会丢。

- **问一句**：按 `Enter` 才发，回一段**带出处**的答案，答案下面摊开引擎读过的原文，可以自己核对。
- **找东西**：边打边搜，回结果列表。分三级出结果：先出最近打开的，再出关键词命中，最后补语义。
  **先出来的不会重排**，所以看到一半不会被抽走。

默认用哪个：设置 → 外观 →「输入框默认干什么」。

---

## 6. 三种投喂方式

1. **拖进来**：文件/文件夹直接拖到窗口任意位置，搜索框会高亮。
2. **选文件夹**：分析中心 →「投喂内容」，或设置 →「监听的目录」（那里加的会自动跟着变）。
3. **复制即用**：开了剪贴板哨兵后，复制的内容进托盘等你点，**不自动入库**——
   密码、验证码、私钥都经过剪贴板。

---

## 7. 更新

**安装版**：设置 →「应用更新」。启动时自动查一次，查到新版侧栏「设置」上会挂一个小点。
下载完点「重启并安装」。跳过某一版之后不会再提醒那一版。

**便携版**：单文件自解压包运行时在临时目录里，替换不了正在运行的自己，
所以自动更新对它是关的。软件里会给一条「去下载页手动换」的链接，不会让你反复重试一个注定失败的动作。

**当前没有代码签名证书**，Windows SmartScreen 首次运行会拦一下：点「更多信息」→「仍要运行」。

## 8. 界面调节

| 想要什么 | 去哪里 |
| --- | --- |
| 长时间看不累 | 设置 → 外观 → 主题选「纸感」（纸黄底棕墨字，零性能开销） |
| 再暖一点 | 「护眼色温」调到弱/中/强（这一档是整页滤镜，长列表滚动会略涩） |
| 一屏看更多 | 「列表密度」选「紧凑」 |
| 字更大 | 「字体方案」选「全思源宋体」 |
| 侧栏太占地方 | 点侧栏最下面的「收起」，或把窗口拖窄到 1180px 以下自动收 |
| 常用功能放最上面 | 侧栏里每一项右边有个图钉，钉住的排到「常用」组 |

窗口拖窄到平板宽度时，双栏会自动并成单栏、左右留白自动收窄，内容仍然占满。

## 9. 卡了 / 不对劲的时候

| 现象 | 先做什么 |
| --- | --- |
| 搜索没反应 | 看左下角圆点。灰=引擎没起来，红=起失败，绿=正常 |
| 引擎起不来 | 界面正中会摊开缺什么、怎么补，点「我自己装好了，重试」 |
| 结果明显少 | 看结果上方的「理解成了什么」小标签——多半是有个筛选在起作用 |
| 一条都没搜到 | 页面会给出补救方案（每条带确切条数），点一下直接重搜 |
| 索引很慢 | 设置 → 性能 → 调「分析并发度」。分析在独立进程里跑，调多高界面都不卡 |
| 图片分析慢 | 设置 → 性能 → 开「启用核显加速」，然后点旁边的「重载」当场生效 |
| 误删了东西 | `Ctrl+Z`；或文件管理器 → 回收站（保留 30 天，能按原路径恢复） |
| 想回到十分钟前那一屏 | 顶栏的闪回按钮，恢复查询词+筛选+预设 |

## 10. 数据在哪里

全部在本机一个 SQLite 文件里，拷走它就是完整备份。
路径见 设置 → 库。卸载**不会**删这个文件。

联网只有你主动用「研究工作台」或开了云端增强时才发生，
每一项在 设置 → 隐私 里逐条列着「开了它会泄漏什么」。
