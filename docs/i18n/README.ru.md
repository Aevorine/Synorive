# Synorive

**Локальный мультимодальный поиск по вашим собственным файлам — и веб-исследователь, который сам ищет опровержения.**

Ищите свои документы, код, изображения, видео и веб-архивы **по смыслу**, а не по имени файла.
Затем — поиск по открытому вебу сразу в нескольких движках, перекрёстная проверка каждого
утверждения и сводка, в которой **каждая строка дословно взята из реального источника**.

Работает полностью офлайн. Ваши файлы никогда не покидают компьютер.
Предоставляет 24 инструмента для **Claude Code** через MCP.

## Что он делает

| | |
|---|---|
| 🔍 | **Семантический поиск по вашим файлам** — документы, исходный код, PDF (с разбивкой по разделам), изображения (OCR), видео (с точностью до секунды), веб-архивы |
| 🖼 | **Кросс-модальный поиск**: найдите изображение по описанию или узнайте, *из какого видео взят кадр и на какой секунде* |
| 🌐 | **Поиск сразу в нескольких движках** — Bing / Baidu / 360 / Mojeek / Википедия, а также Google и DuckDuckGo через собственный SearXNG |
| 🛡 | **Активно ищет опровержения** — находит разоблачения, прослеживает утверждение до самого раннего источника, помечает отозванные статьи |
| 📋 | **Сводки только из цитат** — каждая строка это дословная цитата с указанием источника. Противоречащие утверждения показываются **рядом, без вердикта** |
| 🔌 | **24 инструмента MCP для Claude Code** — агент сам ищет в вашей библиотеке и проверяет утверждения |
| 🔒 | **Барьер приватности** — веб-поиск и облачный вывод это **два разных** переключателя: первый раскрывает *о чём вы спрашиваете*, второй — *что у вас есть* |

## Зачем ещё один поисковик

Большинство инструментов «поиск по вашим файлам» останавливаются на совпадении ключевых слов,
а большинство «ИИ-исследователей» выдают гладкую сводку, которую невозможно проверить.
Synorive отказывается и от того, и от другого:

- **Производительность измерена, а не заявлена.** Каждая цифра в README получена на реальных
  данных, **включая две, которые не достигли цели** — они перечислены с объяснением причины,
  а не тихо убраны.
- **Ничего не отбрасывается молча.** Отфильтрованные как некачественные результаты попадают
  в ящик «исключено» с указанием причины и возвращаются одним щелчком.
- **Он никогда не говорит, что нечто ложно.** Он находит тех, кто оспаривает утверждение,
  и показывает обе стороны — судить об истине он не умеет, а притворяться было бы
  самым опасным, что он может сделать.

## Установка

**Windows** — со страницы [Releases](https://github.com/Aevorine/Synorive/releases/latest):

- `Synorive-Setup-0.1.1.exe` — установщик, **со встроенным автообновлением**
- `Synorive-0.1.1-portable.exe` — портативная версия (без автообновления: файл заменяется вручную)

> Среда Python уже включена в установщик.
> **Устанавливать Python заранее не нужно.**

**Android** — скачайте `app-release.apk` и разрешите установку из неизвестных источников.
Мобильное приложение это тонкий клиент: оно подключается к движку на вашем ПК в той же локальной сети.

## Из исходников

```bash
npm install                                   # Node ≥20
python scripts/build_fonts.py                 # подмножества шрифтов (6 МБ, вне репозитория)
python -m venv engine/.venv                   # Python ≥3.11
engine/.venv/Scripts/pip install -e "engine[docs,media,sync,ann]"
npm run dev                                   # Electron + Vite; движок запускается сам
```

Только проверки компиляции: `npm run typecheck` · `node scripts/check-hardcoded-style.mjs`

## Подключение к Claude Code

```bash
claude mcp add synorive -- node <путь-к-репозиторию>/mcp/dist/index.js
```

После этого достаточно попросить: «найди в моей библиотеке „почему векторный поиск медленный“
и перепроверь то, что найдёшь».

## Несколько неочевидных решений

- **Трёхуровневый каскад поиска** (ключевые слова → семантика → переранжирование): первый экран
  появляется сразу, медленные уровни переупорядочивают результаты позже. Ждать не приходится.
- **Китайскому нужна предварительная сегментация**: без jieba двухсимвольные слова вроде «搜索»
  имеют нулевую полноту.
- **Сводка из цитат и сгенерированная сводка разделены**: дословные цитаты слева, текст ИИ справа,
  их всегда можно сопоставить. Сгенерированная фраза никогда не выдаётся за цитату.
- **Веб-поиск и облачный вывод это два переключателя**: многие принимают одно и категорически
  отвергают другое; объединить их значило бы навязать выбор.
