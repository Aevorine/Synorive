# Synorive

**بحث محلي متعدد الوسائط في ملفاتك الخاصة — وباحث ويب يبحث بنفسه عن الأدلة المضادة.**

ابحث في مستنداتك وشيفرتك وصورك ومقاطع الفيديو وأرشيف الويب **بالمعنى**، لا باسم الملف.
ثم ابحث في الويب المفتوح عبر عدة محركات، وتحقّق من كل ادّعاء بمقارنته بمصادر أخرى،
واحصل على موجز **كل سطر فيه اقتباس حرفي من مصدر حقيقي**.

يعمل دون اتصال بالكامل. ملفاتك لا تغادر جهازك أبدًا.
يوفّر ٢٤ أداة لـ **Claude Code** عبر MCP.

## ماذا يفعل

| | |
|---|---|
| 🔍 | **بحث دلالي في ملفاتك** — المستندات، الشيفرة المصدرية، ملفات PDF (مقسّمة حسب الأقسام)، الصور (التعرّف الضوئي على النصوص)، الفيديو (بدقة الثانية)، أرشيف الويب |
| 🖼 | **بحث متعدد الوسائط**: اعثر على صورة بوصفها، أو اكتشف *من أي مقطع فيديو أُخذت لقطة وفي أي ثانية* |
| 🌐 | **بحث ويب بعدة محركات** — Bing و Baidu و 360 و Mojeek وويكيبيديا، إضافة إلى Google و DuckDuckGo عبر خادم SearXNG خاص بك |
| 🛡 | **يبحث فعليًا عن الأدلة المضادة** — يبحث عن التفنيدات، ويتتبّع الادّعاء إلى أقدم مصدر له، ويشير إلى الأبحاث المسحوبة |
| 📋 | **موجزات بالاقتباس فقط** — كل سطر اقتباس حرفي مع مصدره. الادّعاءات المتضاربة تُعرض **جنبًا إلى جنب دون إصدار حكم** |
| 🔌 | **٢٤ أداة MCP لـ Claude Code** — يبحث وكيلك في مكتبتك ويتحقّق من الادّعاءات نيابةً عنك |
| 🔒 | **حاجز الخصوصية** — البحث على الويب والاستدلال السحابي مفتاحان **منفصلان**: الأول يكشف *عمّا تسأل*، والثاني يكشف *ما تملك* |

## لماذا أداة بحث أخرى

معظم أدوات «ابحث في ملفاتك» تتوقف عند مطابقة الكلمات المفتاحية، ومعظم أدوات «البحث بالذكاء
الاصطناعي» تعطيك ملخّصًا سلسًا لا يمكنك التحقّق منه. Synorive يرفض الأمرين:

- **الأداء مُقاس لا مُدّعى.** كل رقم في هذا الملف قيس على بيانات حقيقية، **بما في ذلك رقمان لم
  يبلغا هدفهما** — وقد أُدرجا مع سبب ذلك بدل حذفهما بهدوء.
- **لا شيء يُستبعد بصمت.** النتائج المستبعدة لضعف جودتها تُوضع في درج «مستبعَد» مع ذكر السبب،
  ويمكن إرجاعها بنقرة واحدة.
- **لا يخبرك أبدًا بأن شيئًا ما كاذب.** يعثر على من يعترض على الادّعاء ويعرض لك الطرفين —
  الحكم على الحقيقة ليس قدرة يملكها، والتظاهر بامتلاكها سيكون أخطر ما قد يفعله.

## التثبيت

**ويندوز** — من صفحة [الإصدارات](https://github.com/Aevorine/Synorive/releases/latest):

- `Synorive-Setup-0.1.1.exe` — مثبّت، **مع تحديث تلقائي مدمج**
- `Synorive-0.1.1-portable.exe` — نسخة محمولة (بلا تحديث تلقائي: استبدل الملف يدويًا)

> بيئة Python مضمّنة داخل المثبّت.
> **لا حاجة إلى تثبيت Python مسبقًا.**

**أندرويد** — نزّل `app-release.apk` واسمح بالتثبيت من مصادر غير معروفة.
تطبيق الهاتف عميل خفيف: يتصل بالمحرّك العامل على حاسوبك ضمن الشبكة المحلية نفسها.

## من الشيفرة المصدرية

</div>

```bash
npm install                                   # Node ≥20
python scripts/build_fonts.py                 # مجموعات الخطوط الجزئية (٦ ميغابايت)
python -m venv engine/.venv                   # Python ≥3.11
engine/.venv/Scripts/pip install -e "engine[docs,media,sync,ann]"
npm run dev                                   # Electron + Vite، والمحرّك يبدأ تلقائيًا
```

<div dir="rtl" align="right">

فحوص الترجمة فقط: `npm run typecheck` · `node scripts/check-hardcoded-style.mjs`

## بعض القرارات التصميمية غير البديهية

- **استرجاع متتالٍ على ثلاث مراحل** (كلمات مفتاحية ← دلالي ← إعادة ترتيب): الشاشة الأولى تظهر
  فورًا، والمراحل الأبطأ تعيد الترتيب لاحقًا. لا انتظار.
- **الصينية تحتاج تقطيعًا مسبقًا**: بدون jieba تصبح نسبة استرجاع الكلمات ذات الحرفين صفرًا.
- **موجز الاقتباسات وموجز التوليد منفصلان**: الاقتباسات الحرفية على اليمين والنص المولَّد على
  اليسار، ويمكن مقارنتهما دائمًا. الجملة المولَّدة لا تُقدَّم أبدًا على أنها اقتباس.
- **البحث على الويب والاستدلال السحابي مفتاحان منفصلان**: كثيرون يقبلون أحدهما ويرفضون الآخر
  رفضًا قاطعًا؛ ودمجهما يعني فرض خيار ثنائي عليهم.
