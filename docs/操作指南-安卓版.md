# Synorive 安卓版操作指南（手机 / 平板）

适用：Android 8.0（API 26）及以上，手机和平板通用。

**先说清楚这个 App 是干嘛的**：它不是一个独立的搜索软件，它是**你那台电脑的遥控器**。
资料、索引、模型全在电脑上，手机只负责"问"和"看"。所以第一步永远是配对。

---

## 1. 安装

| 步骤 | 做什么 |
| --- | --- |
| 1 | 手机浏览器打开 `https://github.com/Aevorine/Synorive/releases/latest` |
| 2 | 下载文件名以 `.apk` 结尾的那个 |
| 3 | 点下载完的文件，系统会问「是否允许从此来源安装应用」，选允许 |
| 4 | 装完打开，底部会看到两个标签：**搜索** / **配对** |

系统拦下来提示"未知来源"是正常的——这个包不是从应用商店来的。
只要签名指纹是 `B1:B6:F3:24:…:D8:89` 就是官方包（下载页每次发布都会写这一串）。

---

## 2. 配对（只做一次）

### 2.1 电脑那边

1. 打开电脑版 Synorive → **设置** → 找到「**安卓配对**」这一栏。
2. 打开开关。它会显示三样东西：
   - **地址**：这台电脑在你家 Wi-Fi 里的 IP，形如 `192.168.1.23`（有多个网卡会全列出来，选和手机同一个网段的那个）
   - **端口**：一个数字，每次启动可能不同
   - **配对令牌**：一串十六进制字符

### 2.2 手机那边

1. 底部点「**配对**」。
2. 三个框照抄：地址、端口、配对令牌。
3. 点「**测试连接**」。
   - 绿色 = 通了，继续下一步
   - 红色 = 看下面第 6 节
4. 点「**保存配对**」。

### 2.3 必须满足的条件

- 手机和电脑**在同一个 Wi-Fi 下**（手机开流量不行，公司/学校的访客网络常常禁止设备互访）
- 电脑版 Synorive **开着**，左下角圆点是绿的
- 电脑防火墙第一次会弹窗问是否允许，选「专用网络」允许

不想再连了：配对页最下面点「**忘记这台设备**」，令牌会从手机上清掉。

---

## 3. 搜东西

1. 底部点「**搜索**」。
2. 上面那个框输入关键词，边打边出结果。
3. 点任意一条打开详情。

顶部显示「未配对 / 连不上」时点它，会直接跳到配对页。

---

## 4. 拍照搜索

1. 搜索页右上角点**相机图标**。
2. 对着要找的东西拍一张。
3. 自动上传给电脑，回来的是**你自己库里**跟这张图相关的内容。

第一次会问相机权限，拒绝了就只能用文字搜——不影响别的功能。
平板没有摄像头也能正常装、正常用，只是这一项灰着。

---

## 5. 从别的 App 分享进来（最常用的一个）

在**任何** App 里点分享，选 Synorive：

| 分享的东西 | 会发生什么 |
| --- | --- |
| 一段文字 / 一个链接 | 存进电脑的资料库，之后电脑上搜得到 |
| 一张图 | 让你选：**存进资料库** 还是 **以图搜图**（找这张图的出处） |
| 一段视频 | 视频反查，找来源 |

具体步骤：微信/浏览器/相册里长按 → 分享 → 在应用列表里选 Synorive → 选要做什么 → 确认。

---

## 6. 连不上的排查顺序

按这个顺序试，一条一条排除：

| 第几步 | 检查 | 怎么确认 |
| --- | --- | --- |
| 1 | 电脑版开着吗 | 电脑上看左下角圆点是不是绿的 |
| 2 | 同一个 Wi-Fi 吗 | 手机 Wi-Fi 名 = 电脑 Wi-Fi 名（手机不能用流量） |
| 3 | IP 抄对了吗 | 电脑设置页里的地址会变（换 Wi-Fi、重启路由都会变），回去重抄 |
| 4 | 端口抄对了吗 | 端口是每次启动动态分配的，**重启过电脑版就要重抄** |
| 5 | 防火墙 | Windows 防火墙 → 允许应用通过 → 找到 Synorive → 勾上「专用」 |
| 6 | 令牌 | 电脑上关掉再打开「安卓配对」开关会换一个新令牌，手机要跟着改 |

访客网络 / 公司网络里设备之间常常互相不可见，这种情况换个网络，不是软件的问题。

## 7. 更新

App 内置检查，也可以手动：

1. 打开 App，有新版时首页会浮出一张**更新卡片**，写着新版本号和包大小。
2. 点「下载」，等进度条走完。
3. 点「安装」，系统弹出安装界面，点「安装」。
4. 第一次会跳到「允许安装未知应用」的系统设置页，把 Synorive 打开，再返回重点一次「安装」。

几件值得知道的事：
- 下载中断不会留下坏文件（下载时文件名是 `.part`，完整了才改成 `.apk`）
- 只从 `github.com` 下载，改不了成别的地址
- **新版必须和旧版是同一个签名才装得上**，这是 Android 自己的规矩，也是防冒牌包覆盖你的机制
- 不想升某一版就先不点，卡片不会强制

---

## 8. 隐私

- 手机上**不存**你的资料，只存三样东西：电脑的地址、端口、配对令牌。
- 所有请求都带令牌，电脑那边校验不过直接拒（401）。
- 令牌比对用的是恒定时间比较，防止在局域网里被一位一位试出来。
- **正式版一行网络日志都不打**——同一台手机上别的 App 读不到"你什么时候搜了什么"。
- 「忘记这台设备」会把令牌从手机上清掉。

---

## 9. 平板上的差别

没有差别。同一个包，布局跟着屏幕宽度走：
屏幕宽的时候列表和详情会并排显示，窄的时候上下叠。横竖屏切换不会丢当前状态。
